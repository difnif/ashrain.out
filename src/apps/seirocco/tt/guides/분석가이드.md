## 1. 들어 있는 것

| 위치 | 내용 |
|---|---|
| `채점결과.csv` / `채점결과.json` | 학생·프린트·문항마다 정답, 학생 답(답 입력 채점일 때), 결과(맞음·틀림·안 풂·안 매김 = 최종), **1차·2차·3차 결과**, 차수별 흐름(예: `1차 X → 2차 O`), 채점 회차, 매긴 때, 매쓰플랫 유형·정답률 |
| `학생/<이름>/<프린트 코드>/채점.md` | 그 학생의 그 프린트 결과 표 |
| `학생/<이름>/<프린트 코드>/스캔_NN.pdf(jpg)` | 학생이 푼 종이 스캔본 — **풀이 과정 검토의 근거** |
| `프린트/<제목 코드>/` | 시험지.pdf(이름 없는 판), 정답해설.pdf, 문항/NNN.png(문항 그림), 정답/NNN.png, 해설/NNN.png |

- 번호(NNN)는 강사도구 시험지 번호다. 스캔본의 번호와 같다.
- `안 풂`은 아이가 아직 풀지 않은 문항(채점 회차가 나뉘어 있으면 나중에 이어서 푼 기록이 있다). `안 매김`은 선생님이 아직 채점하지 않은 문항이다.
- **1차** = 처음 푼 결과. **2차·3차** = 틀리거나 안 푼 문항만 다시 풀게 해서 매긴 결과. `결과`는 최종(가장 마지막 차)이다. 1차에 틀리고 2차에 맞힌 문항은 "스스로 고친 것"으로, 2차에도 틀린 문항은 "혼자서는 못 고친 것"으로 나눠 본다.
- 정답 칸이 `(그림)`이면 `정답/NNN.png`를 본다.

## 2. 해 줄 일

1. 스캔본을 문항 번호와 맞춰 읽는다. 채점 결과(O/X)가 스캔본과 어긋나 보이면 따로 표시한다(채점 실수일 수 있음).
2. 틀린 문항마다 **왜 틀렸는지**를 풀이에서 찾는다: 개념 오해 / 식 세우기 / 계산 실수 / 문제 잘못 읽음 / 단위·표기 / 끝까지 못 감 / 판단 불가.
3. 맞은 문항도 풀이가 불안한 것(답만 맞음, 우연, 비효율)은 짚는다.
4. 같은 유형을 여러 번 틀렸는지(유형·정답률 열), 지난 회차에 안 푼 것을 나중에 풀었는지, 2차·3차에서 고쳤는지 본다.
5. 학생마다 보고서를 만든다(아래 형식). 여러 명이면 학생별로 따로.

## 3. 보고서 형식 (Park 선생님이 정한 것)

- **A4, 흑백, PDF** (HTML로 짜서 PDF로 인쇄). 한국어, 평서체 「~다」.
- 순서:
  1. **첫머리 요약 상자** — 이번 범위에서 이 학생에 대해 가장 중요한 것 2~3줄.
  2. **채점 결과 표** — 프린트별 맞음·틀림·안 풂, 점수(배점이 있으면).
  3. **틀린 문항** — 원인별로 묶어서(개념 / 식 세우기 / 계산 / 읽기 …). 문항마다 번호, 학생이 쓴 것, 어디서 어긋났는지, 바른 흐름 한두 줄.
  4. **판단이 필요한 곳** — 스캔이 흐리거나 채점과 풀이가 어긋나는 곳, 부분 점수 판단이 필요한 서술형 등. 선생님이 정할 것을 분명히.
  5. **습관과 잘한 점** — 풀이 습관(식 정리, 검산, 그림 그리기 등)과 칭찬할 점.
  6. **지도 포인트** — 다음 수업에서 할 것 3개 안팎, 구체적으로(어떤 유형을 어떤 순서로).
  7. **확인 그림** — 판단 근거가 된 스캔 부분을 잘라 붙임(문항 번호 표시).
- 중2 과정 해설에는 제곱근(√)을 쓰지 않는다. 학년 범위를 넘는 풀이를 권하지 않는다.
- 학생 이름은 보고서 제목에만 쓴다.

## 4. 주의

- 스캔본에서 읽을 수 없는 부분은 추측하지 말고 "읽을 수 없음"이라고 적는다.
- 프린트 문항은 학원 수업 자료다. 보고서에 문항 전문을 옮겨 적지 말고 번호와 필요한 부분만 인용한다.
