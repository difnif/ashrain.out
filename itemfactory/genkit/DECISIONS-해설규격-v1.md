# 해설·도식·애니메이션 규격 v1.0 (확정 — 2026-09-07, Park)

> "이렇게 확정해서 가자." 이후 시드·렌더러·플레이어는 이 규격을 따른다. 바꾸려면 이 문서를 먼저 고친다.
> 구현: `src/lib/figsvg.js`(도식) · `src/lib/figanim.js`(플레이어) · `src/lib/mathir.js renderHtml`(분수) · `itemfactory/genkit/`(시드 규격은 `SEEDSPEC.md`).

## 1. 해설 구조
- 기하 = 2단(도형 읽기 / 계산·결론), 그 외 = 3단(방침 / 전개 / 확인). 단계마다 도식 + 애니메이션 큐 + 모범답안 + 채점기준(루브릭).
- 서술형 답안으로 그대로 옮겨 쓸 수 있을 만큼 상세하게. 문제에 그림이 없어도 해설에는 손그림 수준 도식을 둔다.

## 2. 표기
- 분수는 손글씨처럼 **상하(분자 위·가로줄·분모 아래)**. 마커 `[[frac]]`뿐 아니라 평문 `x/5`, `(30 − x)/6`도 세운다. 단위(`m/분`, `km/h`)는 그대로. 가로줄이 글줄 가운데에 오도록 정렬.
- 조사는 조사 함수로(숫자·영문 이름 모두). `÷ 1`·`× 1`·`1x` 같은 항등 표기는 쓰지 않는다(`dv`, `co`).

## 3. 판서(steps) 애니메이션
- **풀이 줄은 처음부터 전부 보인다.** 애니메이션은 현재 줄 배경 강조 + 아래 설명 굵게, 그리고 작게 빨간 글씨로 붙는 메모(암산·주의)가 그 순간 왼쪽→오른쪽으로 써지듯 나타나는 것뿐.
- 계산 요령: 곱셈은 미뤄 두고 마지막에 약분, 소인수분해 암산은 식 위에 작게 다른 색, 덧표시(×L 등) 후 다음 줄.

## 4. 도형 애니메이션
- 문제에 주어진 것 + 보조선을 **한 번에 다 그려 두고** 색으로 강조하며 설명을 따라간다. 단계적으로 그리지 않는다.
- 강조 = 선 색 + 은은한 형광펜 번짐(glow). 글자는 노란 형광펜 배경. 과하지 않게, 눈으로 따라갈 만큼만.
- 각은 실제 크기와 같아야 한다(scene 좌표 직접 계산, 등축).
- 유형별: 일차함수 = 기울기 삼각형 / 통계 = 다 그려놓고 강조 / 경우의 수 = ㄷ·ㅌ자 표 배열, 가지 뻗기는 세는 방식만 최소로 / 입체 = 나란히 대응·접히는 3D 두 옵션을 유저가 골라 재생(하위권엔 접힘 필요) / 위치관계 = 이름 붙은 골격(wire) 위에 기준 → 만남 → 평행 → 꼬인 위치 순 강조. **농도는 보류.**

## 5. 상황 도식 (활용)
- 원칙: **상황을 간단하고 직관적인 그림 하나로** 옮기는 훈련이 목적 — 그래야 식이 그대로 읽히고 실수가 준다. 새 유형은 "샤프로 3초에 그릴 그림"을 먼저 정하고 도식을 추가한다.
- 이동(journey) = 수직선, 기차(passing) = 둥근 직사각형 + 두꺼운 선(앞머리와 다리 끝 이격 0), 강물(river) = 두 줄 강 + 강 안에 강물 방향·속력, 위 순방향·아래 역방향 조건, 등산(mountain) = 우상향 굵은 초록 직선, 오를 때 조건 왼쪽·내려올 때 반대편.
- 액체(vessel) = 컵/실린더/탱크, 물 파랑·소금(용질) 빨강 바닥층, 용기 같은 크기에 양만큼 차오름. 막대(bar)는 액체에 쓰지 않는다.
- 이동 문제만 실제로 움직인다. 그 밖은 전부 한 번에 그리고 강조만.

## 6. 재생
- 기본 1× = 단계 2.4초·이동 3.3초(예전 속도가 지금의 1.5×). 그림 오른쪽 위 `1.5×` 토글. 하단 진행바 클릭·드래그로 위치 이동(단계 눈금). 그림 클릭 = 일시정지/재생, 끝난 뒤 클릭 = 처음부터. 화면에 45% 들어오면 자동 재생.

## 7. 서술형 채점기준 (rubric v3 — 2026-09-08 보정)
- **배점 5~8점.** 핵심 채점 요소 2~4개(2개 5점 · 3개 7점 · 4개 8점). 요소마다 **수행 수준** 세 단계: 정확(만점) / 부분(전형적 실수를 이름 붙여 적은 문구) / 0점("무응답 또는 그 외 오답").
  — 경기도교육청 정기시험 논술형 채점기준표(채점 요소 × 배점 × 수행 수준)의 구조를 따른다. 참고 발췌: `itemfactory/reference/gyeonggi/`.
- **감점 요인 = 그 문항의 실수거리(checks).** 채점 규칙표가 아니라, 빠지면 논리가 끊기는 진술·선후가 뒤바뀌기 쉬운 성질·바꿔 쓰기 쉬운 두 값을 틀마다 2~4개 적고 어느 요소를 부분/불인정으로 매길지 표시한다(`tools/pitfalls.py`). 일반 감점표(계산 실수 −1, 단위 −1 …)는 두지 않는다.
- **공통 채점 원칙 5개**를 모든 채점기준에 붙인다: 방법이 달라도 논리가 맞으면 정답 / 앞 단계 오류를 이어받은 뒤 단계는 독립 인정 / 개념 오류와 단순 계산·필기 실수를 구분(오타는 감점 없음) / 과정 서술 요소는 결과만 쓰면 불인정 / 단위는 성취기준이 아니면 미평가.
- 구현 `genkit/rubric.py` — 옛 형식 시드도 자동 정규화. 시드는 `rubric_total`·`pitfalls` 로 조정. G5 관문이 총점 5~8·배점 합·실수거리 존재를 검사.
