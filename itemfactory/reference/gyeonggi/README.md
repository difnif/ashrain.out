## 구조 — 교육청 채점기준표의 뼈대

`문항 | 평가 요소 | 채점 요소 | 배점 | 수행 수준(채점기준)`. 채점 요소마다 배점을 2·3·5점으로 두고 **수준 문구**를 쓴다:
만점 = "…을 모두 구하고 그 과정을 논리적으로 서술함", 부분(1점) = "둘 중 하나만 / 과정 없이 결과만 / …을 반대로 설정 / 근거 없이 결과를 다시 표현",
0점 = "무응답 또는 그 외 오답". 문항 총점은 6~8점(정기시험 도구), 문항집은 문항당 2~5점 요소를 여러 개.

## 부분(1점) 수준 문구의 유형 — 우리의 '실수거리' 어휘

1. **근거 누락** — 결과는 맞지만 성질·정의·조건을 밝히지 않음 ("계산 과정이나 서술 없이 두 확률만 구함", "설명에 판별식을 언급하지 않음")
2. **결과를 근거처럼 씀(순환)** — "'모양이 변하지 않는다'는 …결과를 포괄적으로 다시 표현한 것이므로 미인정"
3. **방향·관계 뒤집힘** — "대소 관계를 반대로 설정", "부등식이 아닌 등식으로 표현", 부등호 방향
4. **둘 중 하나만** — 두 값·두 경우·두 조건 중 하나만 옳음 (가장 흔한 1점 문구)
5. **미지수·기호 정의 누락** — "미지수를 정의하고 …나타냄"이 만점 조건; 정의 없이 식만 세운 경우는 협의 대상
6. **단위·맥락 해석 모호** — "왕복이나 편도의 단위를 모호하게 서술"
7. **앞 단계 오답 승계** — 감점이 아니라 **독립 채점**으로 인정 ("1-1의 오답을 이용하여 식을 논리적으로 서술함" = 1점 인정)

## 채점 시 유의점에서 반복되는 원칙 (→ genkit/rubric.py PRINCIPLES)

- 예시 답안과 방법이 달라도 논리적 오류가 없으면 정답 인정 (거의 모든 문항)
- 앞 단계 오류를 뒤 단계 감점으로 잇지 않음 (독립 채점)
- 개념 오류와 단순 계산 실수·필기 실수(오타)를 구분, 오타는 감점하지 않음
- 과정 서술 없이 결과만 맞은 경우 인정하지 않음 (과정이 요소일 때)
- 단위는 성취기준이 단위가 아니면 평가하지 않음 ("단위 작성 여부는 채점 시 고려하지 않음")
- 미지수 설명 없이 식을 세운 경우, 눈금에서 살짝 벗어난 점 등은 사전 협의 사항

## 우리 규격에 반영한 것 (DECISIONS-해설규격-v1 §7)

- 채점 요소 × 수행 수준(정확/부분/0) 구조, 0점 문구 고정
- 감점표 대신 **틀별 실수거리(checks)** — 위 1~6 유형으로 씀 (`tools/pitfalls.py`)
- 공통 채점 원칙 5개를 모든 채점기준에 붙임
