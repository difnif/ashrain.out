- 한 문항 = 지문 `[N점]` + 정답 + 풀이(각 단계 끝에 `…… ➊`) + **채점 기준 표(요소 문구 | 배점)**. 부분 수준(1/0)이나 유의점은 없다 — 요소마다 "했다/안 했다"만 있다.

### 설명하기 요소의 쓰임
"구하는 수는 (a, b, c의 공배수)+1 꼴임을 설명하기 (3)" 처럼 **풀이의 전제가 되는 진술을 첫 요소로 두고 가장 큰 배점**을 준다. 우리 `pitfalls` 중 "빠지면 논리가 끊기는 진술" 은 동아에서는 감점이 아니라 **독립 요소**로 처리된다 → 그런 pitfall 은 요소로 승격하는 편이 관행에 맞다.
